# 프로필 이미지 오류 수정과 업데이트

게시글 작성자의 이미지가 없거나 로드에 실패하면 공용 Avatar 대체 표시로 전환한다. 정상 이미지는 DB에 저장된 주소로 표시하며, 이미지 오류 때문에 깨진 이미지 요소가 남지 않게 한다.

관리자 로고를 포함한 실제 프로필 사진은 사이트별 데이터다. 소스 업데이트에서 `users.image`를 초기화하거나 사용자 업로드를 덮어쓰지 않는다. 새 배포 디렉터리의 `public/uploads`는 기존 공용 업로드 경로에 연결하고, DB의 프로필 주소가 가리키는 파일을 계속 같은 URL로 제공해야 한다. 사이트별 이미지나 DB 덤프를 공식 저장소에 포함하지 않는다.

쇼케이스 갤러리·전용 홈페이지 위젯·모바일 쇼케이스 바로가기는 nexibase.com 운영 사이트의 별도 수정사항이다. 공식 기본 기능에는 포함하지 않으며, 운영 사이트를 업데이트할 때 그 사이트의 수정사항을 별도로 보존한다. 공식 소스의 공통 오류 수정을 적용하는 과정에서 사이트별 메뉴·홈 위젯·게시글을 초기화하거나 설치 시드를 다시 실행하지 않는다.

플러그인 스캔 후에도 작성자 이미지 오류 처리 코드가 유지되는지 회귀 검사하며, GitHub Actions에서 전체 테스트·타입 검사·프로덕션 빌드를 실행한다. 기존 쿠키 동의 제거와 재도입 방지 검사도 유지한다.
