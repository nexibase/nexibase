# v0.33.0 — 메뉴 드래그앤드랍 정렬

관리자 메뉴 화면에서 드래그앤드랍으로 메뉴 순서와 상하위 관계를 변경할 수 있습니다.

## 변경 내용

- `/admin/menus`의 위·아래 화살표를 드래그 핸들로 교체했습니다. 헤더와 푸터 각각에서 메뉴를 원하는 위치로 옮기면 자동 저장됩니다.
- 좌우로 이동해 하위 메뉴로 넣거나 최상위 메뉴로 꺼낼 수 있습니다. 기존과 같이 2단계 메뉴 구조를 지원하며, 상위 메뉴를 옮기면 하위 메뉴도 함께 이동합니다.
- 키보드로도 조작할 수 있습니다. 핸들에서 Space로 이동을 시작하고, 방향키로 순서·단계를 조정한 뒤 Space로 확정하거나 Esc로 취소합니다.
- 저장에 실패하면 이전 상태로 되돌립니다. 다른 관리자가 먼저 메뉴 구조를 변경한 경우에는 충돌을 감지하고 새로고침을 안내합니다.
- 정렬 API가 잘못된 ID, 중복 항목, 순환 구조, 3단계 구조와 헤더·푸터 간 잘못된 연결을 거부하도록 검증을 보강했습니다. 순서와 상하위 관계는 하나의 트랜잭션으로 저장합니다.
- 관리자와 사용자용 메뉴 조회에서 순서가 같은 항목도 ID를 기준으로 일관되게 표시합니다.

## 업데이트 안내

v0.32.0에서 업데이트할 때 추가 DB 마이그레이션은 필요하지 않습니다. 기존 메뉴 데이터·URL과 다른 설정은 유지합니다.

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
npm ci
npm run build
# Restart the application using your deployment process.
```

## 검증

- 전체 자동 테스트 81개와 프로덕션 빌드를 통과했습니다.
- dev 환경의 API 검증 28개에서 정렬·계층 저장, 잘못된 요청의 원자적 거부, 변경 충돌과 관리자 권한을 확인했습니다.
- dev 브라우저에서 드래그 후 새로고침, 하위 메뉴 동반 이동, 키보드 정렬·계층 변경, Esc 취소와 푸터 정렬을 확인했습니다. 임시 검증 메뉴는 제거했고 기존 메뉴 데이터는 유지했습니다.
- 전체 TypeScript 검사에는 기존 seed·플러그인 코드의 오류가 남아 있습니다. 빌드는 기존 프로젝트 설정을 따릅니다.
