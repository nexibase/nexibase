# v0.32.0 — 기본 게시 기능과 FAQ 통합

게시판·콘텐츠·약관·FAQ를 기본 기능으로 통합하고, FAQ 조회·평가 기록과 관리자 화면을 개선합니다.

## 변경 내용

- 게시판, 콘텐츠, 약관과 FAQ가 플러그인 활성화 상태와 관계없이 제공됩니다. 플러그인 목록에서 제외되며 기존 DB 테이블, 데이터, URL, 위젯 키를 유지합니다.
- FAQ 기본 경로는 `/faqs`, 관리 경로는 `/admin/faqs`입니다. `/faq`, `/faq-accordion`과 이전 API 경로는 호환 경로로 유지합니다. 분류는 `/faqs` 안에서 필터로 선택합니다.
- FAQ 질문 제목은 `/faqs#faq-{id}` 링크입니다. 직접 접근, 새 탭, 새로고침과 브라우저 뒤로 가기로 해당 답변을 열 수 있습니다.
- FAQ 조회수와 도움됨·도움 안 됨은 질문별로 계정 또는 서명된 비로그인 브라우저 ID당 한 번만 집계하고 DB에 기록합니다. 반복 열기와 새로고침으로 중복 집계되지 않습니다.
- 비로그인 식별에는 1년 유효한 HttpOnly 쿠키를 사용합니다. 쿠키 삭제나 다른 브라우저 사용은 새로운 비로그인 식별자로 처리됩니다. 기존 누적 수치는 유지하고, 과거 기록의 사용자 정보는 소급 생성하지 않습니다.
- 관리자 FAQ에서 조회수·도움됨·도움 안 됨을 클릭하면 로그인 사용자와 비로그인 사용자를 구분한 상세 내역을 볼 수 있습니다.
- 관리자 본문 너비와 여백을 대시보드 기준으로 통일했습니다. 설정은 대시보드 바로 아래, 약관은 FAQ 바로 위, 로그인 기록은 플러그인 바로 위에 표시합니다. 모든 기본 메뉴는 플러그인 운영 메뉴보다 위에 둡니다.
- 남아 있던 옛 `/admin/members` 화면을 현재 사용자 관리에 연결했습니다. 목록·추가·수정 주소를 지원하며 수정 대상은 숫자 ID 또는 UUID로 지정합니다. 조회 실패를 표시하고 저장 후 DB 반영을 유지합니다.
- 기존 개발 서버의 홈 위젯·이미지·데이터 준비 및 렌더링 개선을 포함합니다.
- Shop v1.3.1을 연결하여 쇼핑몰 관리자 화면도 같은 본문 너비로 표시합니다.

## 업데이트 안내

기존 설치의 DB와 업로드 파일을 백업하고 로컬 변경을 보존한 다음 업데이트하세요.

1. main을 갱신하고 서브모듈을 동기화합니다.
2. 제거된 `src/plugins/faq-accordion` 서브모듈 체크아웃이 디스크에 남아 있다면, 내용을 보존하여 `src/plugins` 밖의 백업 경로로 옮기세요. 새 기본 FAQ와 이름이 충돌하므로 이전 디렉터리를 다시 플러그인으로 스캔하면 안 됩니다.
3. 의존성과 빌드를 갱신하고 FAQ 기록용 마이그레이션을 적용한 뒤 프로세스를 재시작합니다.

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
# If the removed FAQ submodule checkout remains, back it up outside src/plugins first.
npm ci
npm run build
npx prisma migrate deploy
```

- 추가되는 DB 테이블은 `faq_feedback`과 `faq_views`입니다. `faqs`, `faq_categories`, 게시판·콘텐츠·약관 테이블의 기존 데이터와 누적 수치는 유지합니다.
- 배포에는 두 새 테이블의 마이그레이션이 필요합니다. 초기화나 reset 명령은 사용하지 마세요.
- 기존 FAQ 헤더 메뉴가 없다면 관리자 메뉴 화면에서 `/faqs` 링크를 추가할 수 있습니다. 기존 메뉴를 자동으로 덮어쓰지 않습니다.
- FAQ 조회·평가 기록에는 기존 회원 탈퇴 보존 정책을 적용합니다. 관리자 상세 내역은 관리자 권한으로만 조회할 수 있습니다.
