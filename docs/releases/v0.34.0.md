# v0.34.0 — 쿠키 동의 기능 완전 제거

쿠키 동의 기능을 코드와 관리자 설정에서 제거했습니다. 기존 동의·거부 선택과 관계없이, 설정된 Google Analytics가 실행됩니다.

## 변경 내용

- 쿠키 동의 배너, 선택 설정, 알림, 동의 쿠키 처리 및 동의 API를 삭제했습니다.
- 관리자 설정의 쿠키 동의 토글과 관련 번역을 삭제했습니다. 오래된 관리자 화면에서 동의 설정키를 저장하는 요청도 거절합니다.
- 설치 기본값과 정책 초기화에서 쿠키 동의 설정, 쿠키 정책, 해당 메뉴를 제거했습니다.
- DB 마이그레이션으로 기존 `consent_` 설정키, cookie 정책 및 해당 메뉴를 정리합니다.
- Google Analytics의 동의 분기를 제거하고 측정 ID가 설정되어 있으면 직접 로드합니다. 이전 거부 쿠키가 남아 있어도 실행을 제한하지 않습니다.
- 빌드와 GitHub Actions에서 삭제한 기능의 재도입을 검사합니다. 동의 API·설정·모델 등이 다시 포함되면 검사가 실패합니다.

## 업데이트 안내

이 버전부터 쿠키 동의 기능과 `/api/consent`를 제공하지 않습니다. 이전 동의 이력은 보존하며 앱에서는 사용하지 않습니다. 로그인 등 다른 기능에서 사용하는 쿠키는 유지합니다. Shop은 v1.3.2를 유지합니다.

업데이트 전에 DB를 백업하고 다음 명령을 실행하세요.

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
npm ci
npm run db:migrate
npm test
npm run typecheck
npm run build
# 사용 중인 배포 방식에 따라 애플리케이션을 재시작합니다.
```

Docker 배포는 새 이미지 빌드 중 재도입 검사를 실행하고, 시작 시 DB 마이그레이션을 적용합니다. 과거 마이그레이션 파일은 적용 이력을 위해 유지하며 최신 정리 마이그레이션까지 모두 적용해야 합니다. 다음 배포도 이 버전 이상의 소스와 빌드 스크립트를 사용하세요.

## 검증

- 자동 테스트 60개(재도입 감지 테스트 포함), TypeScript 검사, 프로덕션 빌드를 통과했습니다.
- 별도의 빈 DB에 전체 마이그레이션 12개를 적용하고 동의 설정과 쿠키 정책·메뉴가 남지 않는 것을 확인했습니다.
- 운영 사이트에서 동의 배너·설정 링크 제거, 삭제된 API의 404 응답을 확인했습니다.
- 새 방문자와 이전 거부 쿠키가 있는 요청에서 GA 초기화를 확인했고, 실제 브라우저의 방문 통계 전송은 204로 응답했습니다.
