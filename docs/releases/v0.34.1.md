# v0.34.1 — 게시글 프로필 이미지 오류 수정

게시글 작성자의 프로필 이미지가 로드되지 않을 때 깨진 이미지가 표시되던 문제를 수정했습니다.

## 변경 내용

- 작성자 이미지가 없거나 로드에 실패하면 공용 Avatar 대체 표시로 전환합니다. 정상 프로필 사진과 관리자 로고는 기존 주소로 표시합니다.
- 깨끗한 Linux 환경에서 `npm ci`가 실패하던 SWC 선택 의존성의 누락된 잠금 항목을 보완했습니다.
- 프로젝트 내부 임시 작업 파일을 TypeScript 검사 대상에서 제외하고, 전체 테스트·타입 검사·프로덕션 빌드를 자동 검사하도록 구성했습니다.

공식 앱 코드의 v0.34.0 대비 변경은 프로필 이미지 오류 수정입니다. 쇼케이스 갤러리·전용 홈 위젯·모바일 쇼케이스 바로가기는 nexibase.com 운영 사이트의 별도 구성으로 유지합니다. v0.34.0의 쿠키 동의 기능 제거와 재도입 방지 검사도 유지합니다.

## 업데이트 안내

추가 DB 마이그레이션과 데이터 초기화는 없습니다. Shop은 v1.3.2를 유지합니다. 기존 DB·프로필 이미지·공유 업로드와 사이트별 수정사항을 백업하고 보존해 업데이트하세요.

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
npm ci
npm test
npm run typecheck
npm run build
# 사용 중인 배포 방식에 따라 애플리케이션을 재시작합니다.
```

별도 배포 디렉터리를 사용하는 경우 `public/uploads`를 기존 공용 업로드 경로에 연결하세요. 사이트별 화면 수정은 최신 공식 소스와 병합해 유지합니다. 자세한 지침은 [프로필 이미지 업데이트 안내](../maintenance/profile-image-updates.md)를 참고하세요.

## 검증

- 자동 테스트 60개와 TypeScript 검사, 프로덕션 빌드 통과.
- GitHub Actions의 빈 DB 전체 마이그레이션 및 쿠키 동의 재도입 검사 통과.
