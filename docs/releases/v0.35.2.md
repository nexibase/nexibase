# v0.35.2 — Next.js 16.4.3 업데이트

- Next.js를 16.4.3으로 업데이트합니다.
- `eslint-config-next`도 16.4.3으로 맞추고 잠금 파일을 갱신합니다.
- 재설치 시 같은 버전을 사용하도록 두 패키지의 버전을 고정합니다.
- 기존 React 버전과 애플리케이션 설정을 유지하며, DB 구조 변경은 없습니다.

## 검증

- 빈 MySQL DB에 전체 마이그레이션 적용.
- 자동 테스트, TypeScript 검사 및 프로덕션 빌드.

프레임워크 변경 내용은 [Next.js 16.4](https://nextjs.org/blog/next-16-4)와 [16.4.3 릴리스](https://github.com/vercel/next.js/releases/tag/v16.4.3)를 참고하세요.
