# v0.33.2 — 관리자 버전 확인 오류 수정

현재 버전보다 오래된 릴리즈를 업데이트로 안내하던 관리자 패널 표시를 수정합니다.

## 변경 내용

- 버전이 다르기만 하면 업데이트로 처리하던 비교를 수정했습니다. 최신 릴리즈가 설치된 버전보다 높을 때만 “업데이트 가능”으로 표시합니다.
- 숫자 기준으로 major·minor·patch와 사전 릴리즈 순서를 비교합니다. `v` 접두사와 빌드 메타데이터 때문에 같은 버전을 다르게 판단하지 않습니다.
- 브라우저에 남아 있던 이전 10분 세션 캐시를 버리고, 관리자 전용 API에서 GitHub의 게시된 최신 정식 릴리즈를 확인합니다. 첫 번째 태그를 최신 릴리즈로 대신 사용하는 방식도 제거했습니다.
- GitHub 조회는 서버에서 5분간 공유 캐시하며 중복 요청을 합칩니다. 조회 실패는 30초 후 재시도할 수 있고, 네트워크 실패나 잘못된 응답을 업데이트 안내로 표시하지 않습니다.
- 관리자 화면은 창 포커스를 되찾거나 5분이 지나면 버전을 다시 확인합니다. 링크는 해당 릴리즈로 연결됩니다.
- 설치 버전이 최신 릴리즈보다 높으면 업데이트 안내 대신 중립적인 표시와 설명을 제공합니다.

## 업데이트 안내

v0.33.1에서 패치 업데이트하며 추가 DB 마이그레이션이나 데이터 초기화는 없습니다. Shop은 v1.3.2를 유지합니다.

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
npm ci
npm run typecheck
npm run build
# Restart the application using your deployment process.
```

배포 후 관리자 페이지를 새로고침하면 이전 브라우저 버전 캐시가 제거됩니다.

## 검증

- 전체 TypeScript 검사 오류 0건, 자동 테스트 92개와 프로덕션 빌드를 통과했습니다.
- 추가 회귀 테스트 11개로 `0.33.1` / `0.33.0` 오표시, 숫자·사전 릴리즈 비교, 잘못된 응답, 캐시 만료·동시 요청과 통신 실패를 검증합니다.
- 관리자 전용 버전 API의 권한 검사와 브라우저 캐시 금지 응답을 확인했습니다. dev에서 현재·최신 버전이 일치하고 업데이트 오표시가 없는 것을 확인합니다.
