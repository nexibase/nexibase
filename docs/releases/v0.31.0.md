# v0.31.0 — 관리자 사칭 방지

닉네임에 관리자처럼 보이는 이름을 지정하는 것을 막고, 실제 사이트 관리자를 방패와 “관리자” 배지로 구별합니다.

## 변경 내용

- 닉네임에 `관리`, `운영`, `admin`이 포함되면 가입 및 이름 변경을 거절합니다. 영문 대소문자를 구분하지 않습니다.
- Unicode NFKC 정규화와 공백·보이지 않는 문자 제거로 `관 리자`, `a d m i n`, `ＡＤＭＩＮ` 같은 변형도 검사합니다. 정상 닉네임은 원래 표기를 보존합니다.
- 회원가입, 중복 확인, 프로필 편집, 관리자 회원 생성·수정, 초기 설치에 같은 서버 검증을 적용합니다.
- 소셜 계정 이름이 금지된 경우 중립적인 닉네임을 생성합니다. 소셜 정보 갱신은 기존 닉네임을 금지 이름으로 덮어쓰지 않습니다.
- 게시글·댓글·프로필·검색·쪽지 등에 공식 관리자 배지를 표시합니다. DB에서 확인한 활성 `admin` 계정만 표시하며, `manager`와 일반 회원은 대상이 아닙니다.
- 회원 관리에 기존 금지 닉네임 수, 대상 필터와 확인 표시를 추가합니다.
- Shop 플러그인 v1.3.0을 연결하여 상품 리뷰·질문에도 같은 배지를 표시합니다.

## 업데이트 안내

이번 릴리즈는 새 닉네임 정책과 관리자 식별 기능이 추가된 마이너 릴리즈입니다. 기존 닉네임의 허용 범위가 줄어드므로 운영 정책을 확인하세요.

- DB 스키마 변경이나 데이터 마이그레이션은 없습니다.
- 기존 계정과 닉네임을 자동으로 변경하거나 삭제하지 않습니다. 기존 이름을 유지하는 다른 정보 수정은 허용하며, 새 닉네임을 지정할 때 정책을 검사합니다.
- 관리자 계정에도 새 닉네임 규칙을 동일하게 적용합니다.
- Shop을 사용한다면 서브모듈을 함께 갱신하세요. Shop v1.3.0은 NexiBase v0.31.0 이상이 필요합니다.

```sh
git pull --ff-only
git submodule update --init --recursive
npm ci
npm run build
```

프로세스를 재시작하면 버전과 새 기능이 반영됩니다.

## Validation

- Nickname normalization, admin identity and OAuth adapter tests pass.
- HTTPS API verification covers rejected writes, normal nickname checks, authenticated sessions, admin-only routes and public badge identities.
- Existing account identities remain unchanged after verification.
- The external OAuth provider consent/login flow was not exercised; the adapter was tested with a mock database.
