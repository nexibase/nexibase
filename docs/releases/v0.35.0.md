# v0.35.0 — 소셜 전용 회원가입과 이메일 로그인 설정

새 회원은 소셜 계정으로만 가입하도록 설정하면서 기존 회원의 이메일·비밀번호 로그인은 별도로 유지할 수 있습니다.

## 변경 내용

- 관리자 → 설정 → 회원 설정에 **소셜 회원가입만 허용** 토글을 추가했습니다.
- **기존 회원 이메일 로그인 허용** 토글을 별도로 추가했습니다. 끄면 이메일 로그인 화면과 로그인 API·NextAuth Credentials 인증을 함께 차단합니다.
- 소셜 전용 가입 설정은 회원가입 화면과 서버의 회원가입 API에 모두 적용됩니다. 가입 페이지나 API에 직접 접근해도 이메일 가입을 허용하지 않습니다.
- 기존 **회원가입 허용** 설정을 끄면 신규 이메일·소셜 가입을 차단합니다. 기존 소셜 회원의 로그인은 유지합니다.
- 설정 조합과 실제 가입·로그인 핸들러를 검증하는 회귀 테스트를 추가했습니다.

## 기본값과 업데이트 안내

기존 설치의 동작을 유지하도록 기본값은 **회원가입 허용: 켜짐**, **소셜 회원가입만 허용: 꺼짐**, **기존 회원 이메일 로그인 허용: 켜짐**입니다. 기존에 저장된 설정은 유지합니다.

소셜 전용 가입으로 운영하려면 사용할 소셜 로그인 공급자의 키와 콜백 주소를 먼저 설정한 뒤, 관리자 회원 설정에서 **소셜 회원가입만 허용**을 켜고 저장하세요. 기존 이메일 로그인을 유지하려면 **기존 회원 이메일 로그인 허용**을 켜 둡니다. 두 설정은 독립적으로 변경할 수 있습니다.

이번 기능을 위한 추가 DB 마이그레이션이나 회원·게시글·메뉴 초기화는 없습니다. 기존 DB·업로드·사이트별 수정사항을 보존해 업데이트하고 애플리케이션을 다시 빌드·시작하세요. 이전 버전에서 아직 적용하지 않은 마이그레이션은 기존 업데이트 절차에 따라 적용합니다.

## 검증

- 자동 테스트와 TypeScript 검사.
- GitHub Actions의 빈 DB 마이그레이션, 코어 보존 검사, 쿠키 동의 기능 재도입 검사 및 프로덕션 빌드.

소셜 로그인 공급자의 앱 등록·키 발급·심사 상태는 각 공급자 콘솔에서 별도로 관리합니다.
